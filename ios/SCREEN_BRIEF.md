## Hard rules
- **Read before writing:** `Design/Theme.swift`, every file in `Components/`, `Mascot/MascotView.swift`, `Models/Models.swift`, `Services/MockData.swift`, `Services/Engines.swift`, `Services/DateHelpers.swift`, `Store/AppStore.swift`, `Store/Selectors.swift`, `Store/Route.swift`, `App/RootView.swift`, and `Features/Home/HomeView.swift` (reference implementation of the style).
- You own ONLY the files listed in your task. Each currently holds a PLACEHOLDER struct with the exact name and init signature that `RootView`/`RouteView` expect — keep the struct name and stored properties' names/types unchanged. You may add new files in your feature folder (prefix private helper types to avoid name collisions, e.g. `CoachBubble`, `RevenueChart`). Do NOT edit shared files (Components, Store, Models, Services, App, Theme, Mascot). If you truly need a store capability, work around it with existing actions + `store.s` mutation and report it.
- Views get the store with `@Environment(AppStore.self) private var store`. Mutations: call store actions (`store.completeMission(day:)`, `store.setProspectStatus`, …) or mutate `store.s.…` directly for simple fields. Navigation: `store.push(.route)`; tabs: `store.tab = .coach`; full-screen flows: `store.cover = .mission(day)` / `.checkIn` / `.complete`; paywall: `store.paywallFeature = "AI Coach"` or `store.requirePremium("X") { … }`; toasts: `store.showToast("Saved")`, `store.showToast("…", .error)`.
- Every screen: use `Screen(title:subtitle:large:)` scaffold (top-level tab roots use `large: true`; pushed screens use the inline nav title). Full-screen covers (Mission, CheckIn, Complete) build their own chrome with a close button that sets `store.cover = nil`.
- Every visible button must do something real (navigate, sheet, mutate store, toast, copy, share). No dead buttons, no "coming soon", no lorem ipsum.
- Every list needs an empty state (`EmptyStateView` with Penny). Lists that "fetch" show a brief `SkeletonList`/`SkeletonBlock` on first appear (300–700ms via `.task`). If `store.isOffline`, network-like actions (coach reply, generator, checkout, support form) show an error state/toast with Retry.
- Use only Theme tokens (`Theme.surface`, `Theme.muted`, `Theme.brandGradient`, `Space.*`, `Radius.*`, `.card()`, `.buttonStyle(.fr(.primary, size: .lg, full: true))`, `Badge`, `ProgressBar`, `ProgressRing`, `StatCard`, `ListGroup`/`ListRow`, `SectionHeader`, `FilterChips`, `SegmentedTabs`, `SearchField`, `FRTextField`, `FRTextArea`, `SelectRow`, `FRToggleRow`, `FlowLayout`, `Adaptive2Col`, `adaptiveColumns()`, `.fadeUp(i)`, `ConfettiView`, `MascotView(mood:size:)`, `MascotLoader`, `LockedView`, `PremiumGate`, `PlanPicker`, `mockCheckout`, `LessonCard`, `ProspectCard`, `StatusBadge`, `ResourceCard`, `HeatmapView`, `VideoPlayerMock`, `AvatarView`, `LogoMark`, `TrailingIconLabel`). No raw hex colors.
- iPad: content is centered by `Screen` (max width 920). Use `Adaptive2Col` / `LazyVGrid(columns: adaptiveColumns())` so regular width gets real multi-column layouts.
- Accessibility: labels on icon-only buttons, `.accessibilityAddTraits(.isHeader)` for section titles where not using `SectionHeader`, combine card children, respect Dynamic Type (use text styles, avoid fixed heights on text containers), 44pt min touch targets.
- Penny (MascotView) sparingly: at most one per screen, for empty/success/celebration moments.

  `cd /Users/annybabeni/Desktop/revenue/ios/FirstRevenue && xcrun -sdk iphonesimulator swiftc -typecheck -target arm64-apple-ios18.0-simulator $(find FirstRevenue -name '*.swift') 2>&1 | grep -E "error:" | sort -u`
